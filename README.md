# 勤勉性介入プランナー

教育・家庭・支援場面で、子ども・学生・支援対象者の「勤勉性」を高めるための介入設計テンプレートを作る1ページWebアプリです。

HTML / CSS / JavaScriptのみで作られており、外部APIやフレームワークは使っていません。入力データはブラウザのlocalStorageに保存されます。

## 公開デモ版の前提

- データベースは使っていません。
- ログイン機能はありません。
- 決済機能はありません。
- 入力内容は利用中ブラウザのlocalStorageに保存されます。
- Free / Proの切り替えはデモ用です。
- 静的サイトとしてそのまま公開できます。

## プランの違い

| プラン | 料金 | 主な機能 |
| --- | --- | --- |
| Free | 無料 | 1ケース、記録7日分、基本テンプレート、介入計画書作成、印刷 |
| Pro | 月額2,980円想定 | 30ケース、記録無制限、全テンプレート、CSV出力、PDF出力導線、週次レビュー、保護者説明文生成 |
| Team | 月額9,800円想定 | スタッフ複数名、ケース100件、権限管理、施設ロゴ入りレポート、支援会議用レポート、編集履歴 |

Teamプランは料金表に表示していますが、今回のデモ実装ではFree / Proの切り替えのみ利用できます。

## ローカルでの起動方法

1. このフォルダを開きます。
2. `index.html` をブラウザで直接開きます。
3. サーバー起動やインストール作業は不要です。

公開時に必要なファイルは以下です。

- `index.html`
- `style.css`
- `app.js`
- `plans.js`
- `templates.js`
- `review.js`
- `storage.js`
- `README.md`

不要なビルド作業はありません。上記ファイルを同じ階層に置いたまま公開してください。

## デモ用プラン切替

画面上部の「プラン」セクションにある「デモ用プラン切替」から、Free / Proを切り替えられます。

本番環境ではこのUIを非表示にし、ログイン状態や決済状態から現在のプランを判定する想定です。

## localStorageに保存されるデータ

保存キーは `kinbenseiInterventionPlannerSaaS` です。

主に以下が保存されます。

- 現在のプラン
- 現在開いているステップ
- ケース一覧
- 選択中ケースID
- 各ケースの入力内容
- 勤勉性の下位側面
- 日々の記録

旧バージョンの保存キー `kinbenseiInterventionPlanner` が見つかった場合は、新しい複数ケース形式へ移行します。

## ファイル構成

- `index.html`：画面の構造
- `style.css`：見た目とレスポンシブ対応
- `plans.js`：Free / Pro / Teamのプラン設定
- `templates.js`：テンプレート集
- `review.js`：成功率、詳細提案、週次レビュー、保護者説明文の生成
- `storage.js`：保存・読み込み・バックアップ用の保存層
- `app.js`：UI操作、ケース管理、フォーム反映、画面描画

`storage.js` は将来のクラウド保存に差し替えやすいよう、`fetchAppState`、`persistAppState`、`clearPersistedAppState` のような名前にしています。

## プライバシー

このアプリは医療上の診断、治療、心理検査の代替ではありません。

入力内容は、クラウドではなく利用中ブラウザのlocalStorageに保存されます。同じブラウザを使う人がいる場合、保存内容を見られる可能性があります。

子どもの情報を入力する場合は、実名ではなくケース名やニックネームの利用をおすすめします。共有PCや学校・施設の共用端末では、個人情報や特定につながる情報を入力しないでください。

## デプロイ前チェックリスト

- `index.html` を開いて画面が表示される
- `style.css`、`plans.js`、`templates.js`、`review.js`、`storage.js`、`app.js` が同じ階層にある
- ブラウザの開発者ツールでコンソールエラーが出ていない
- スマホ幅でカード、入力欄、ボタンが読める
- Freeプランで1ケース・7記録の制限が動く
- Proデモ切替で複数ケース、Proテンプレート、CSV出力、週次レビューが使える
- JSONバックアップ出力・読み込みが動く
- 共有PCでは個人情報を入力しない注意書きが見える
- APIキー、秘密鍵、個人情報をリポジトリに含めていない

## 公開方法

### GitHub Pages

1. GitHubで新しいリポジトリを作ります。
2. このフォルダ内の公開用ファイルをアップロードします。
3. GitHubのリポジトリ画面で `Settings` を開きます。
4. 左メニューの `Pages` を開きます。
5. `Build and deployment` の `Source` で `Deploy from a branch` を選びます。
6. `Branch` で `main` と `/root` を選び、`Save` を押します。
7. 数分後に表示されるURLを開きます。

### Netlify

1. Netlifyにログインします。
2. `Add new site` から `Deploy manually` を選びます。
3. このフォルダ内の公開用ファイルをまとめてドラッグ＆ドロップします。
4. デプロイが完了したら、表示されたURLを開きます。
5. 独自ドメインを使う場合は、Netlifyの `Domain management` から設定します。

### Vercel

1. Vercelにログインします。
2. `Add New...` から `Project` を選びます。
3. GitHubに置いたリポジトリを選択します。
4. Framework Presetは `Other` または自動判定のままで問題ありません。
5. Build Commandは空欄、Output Directoryも空欄または `.` のままにします。
6. `Deploy` を押します。
7. デプロイ後に表示されるURLを開きます。
